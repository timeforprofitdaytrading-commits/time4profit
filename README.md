## 📌 Sobre el proyecto

Time 4 Profit es una comunidad de trading fundada por **David Pascual** y **Nahuel Tajes**, centrada en Smart Money Concepts, ICT y Order Flow. Esta web es el punto de entrada para la comunidad: formación, señales en directo, sesiones en vivo y noticias del mercado en tiempo real.

## ✨ Funcionalidades

| Sección | Descripción |
|---|---|
| 📊 **Cotización en directo** | Cinta de precios fija (EUR/USD, GBP/USD, Oro, índices, principales criptomonedas) vía TradingView |
| 📰 **Centro de noticias** | Feed de noticias en tiempo real por activo |
| 🎓 **Formación** | Material en PDF de Smart Money Concepts, ICT y Order Flow |
| 📈 **Señales** | Setup en vivo con contexto de mercado, más bitácora de señales por día |
| 🔴 **Sesiones en directo** | Conexión por Google Meet, Londres (08:45–10:45 CEST) y Nueva York (14:30–16:30 CEST) |
| 👥 **Comunidad** | WhatsApp, Telegram, Discord, Instagram y TikTok |
| ✉️ **Contacto** | Formulario de contacto directo al equipo |

## 🛠️ Stack técnico

- **Frontend:** HTML, CSS y JavaScript puro — un único archivo autocontenido (`index.html`), sin frameworks ni dependencias de build.
- **Widgets de mercado:** [TradingView](https://www.tradingview.com/) (ticker tape, noticias por símbolo).
- **Formulario de contacto:** [FormSubmit](https://formsubmit.co/) — sin backend propio.
- **Hosting:** [GitHub Pages](https://pages.github.com/), gratuito.
- **Backend de noticias (proyecto aparte):** Cloudflare Workers + D1 + API de Claude, para traducción y clasificación automática de noticias por activo — repositorio independiente.

## 🚀 Cómo actualizar la web

1. Sustituye el archivo `index.html` de este repositorio por la versión nueva.
2. Confirma los cambios (**Commit changes**).
3. GitHub Pages publica la nueva versión automáticamente en la URL de arriba, sin pasos adicionales.
